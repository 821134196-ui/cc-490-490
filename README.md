# 公交场站轮椅坡板点检与车辆放行系统

车辆出场前按班次点检轮椅坡板（外观/承重标识、展开收回、锁止/固定销、车内呼叫按钮），
全部合格才可放行；故障车辆进入无障碍功能停用或整车待修，维修后必须复检合格才能恢复。

## 启动

```bash
python3 app.py
```

首次启动自动建库（`data/depot.db`）、写入演示车辆/线路/人员/班次，并生成
**坡板卡滞、临时换车、复检失败** 三个样例；测试照片存于本地 `photos/`。
界面入口 <http://127.0.0.1:5000/> ，右上角切换身份（驾驶员/调度员/维修人员）。

## 测试

```bash
python3 -m pytest tests/ -q
```

覆盖：班次唯一、同一车辆同一班次一份有效点检、故障阻断放行、换车容量校验、
职责分离（驾驶员点检/调度员换车放行/维修工不能复检）、放行幂等（含 8 线程并发只成功一次）。

## 功能与界面

- **线路待发板**：按线路分组、发车时间排序的高密度行，坡板状态徽标在车辆编号旁；放行（幂等键）、驾驶员交接
- **车辆点检**：侧视车辆轮廓 SVG 标出坡板与呼叫按钮位置；大字体大按钮（驾驶员端）；可读取模拟车载终端信号自动判定展开/按钮项；可附测试照片
- **坡板测试**：模拟适配器返回车载终端与门控信号，展开/收回测试自动记录
- **故障停用**：报修登记（无障碍功能停用/整车待修），自动生成维修单（4 小时时限）
- **备用车调配**：仅调度员；校验备用车状态、无障碍要求与载客容量
- **维修进度**：时限倒计时、超时标记；仅维修人员可完工
- **复检**：维修完成车辆待驾驶员复检；结论图标+文字（✅复检合格 / ⛔复检不合格）
- **放行记录 / 留痕日志**：卡滞、固定销缺失、按钮无响应、承重标识脱落、司机漏检、临时换车、维修延期、误放行拦截全程留痕

## 进程内提醒

后台线程每 5 秒扫描：发车前 15 分钟未点检提醒、过发车时间未点检记"司机漏检"、
维修超时限记"维修延期"，提醒显示在页面顶部横幅并输出到控制台。

## 结构

```
app.py               启动入口
busdepot/
  db.py              SQLite 建表与连接（唯一约束落库）
  domain.py          点检/故障/维修/复检/换车/交接/放行规则
  adapters.py        模拟车载终端与门控信号适配器
  reminders.py       进程内发车时限与维修超时提醒
  seed.py            演示数据与卡滞/换车/复检失败样例
  web.py             Flask API 与静态页面
static/              前端（公交白/线路蓝/无障碍橙）
tests/test_rules.py  核心规则测试
```
